## Problem

Given two integers `num1` and `num2`, return their sum.

## My Approach

Simply add the two integers using the `+` operator and return the result.

## Key Logic

```c
return num1 + num2;
```

## Solution

```c
int sum(int num1, int num2) {
    return num1 + num2;
}
```

## Complexity

Time: O(1)

Space: O(1)

## What I Learned

- Basic function parameters and return values.
- Direct arithmetic operations can solve a problem without loops or extra variables.
- Always look for the simplest solution when the problem itself is simple.
