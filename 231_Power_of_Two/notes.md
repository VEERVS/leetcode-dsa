## Problem

Given an integer `n`, return `true` if `n` is a power of two.

A number is a power of two if there exists an integer `x` such that:

`n = 2^x`

Examples:

- `1 = 2^0` → `true`
- `16 = 2^4` → `true`
- `3` → `false`

## My Approach

I start with `i = 1`, which represents `2^0`.

I repeatedly multiply `i` by `2` until it reaches or exceeds `n`.

If `i == n`, then `n` is a power of two. Otherwise, it is not.

## Key Logic

Starting from `1`:

```text
1 → 2 → 4 → 8 → 16 → 32 → ...
```

For `n = 16`:

```text
i = 1
i = 2
i = 4
i = 8
i = 16
```

Since `i == n`, return `true`.

For `n = 3`:

```text
i = 1
i = 2
i = 4
```

Now `i > n`, so `3` is not a power of two.

## Solution

```cpp
class Solution {
public:
    bool isPowerOfTwo(int n) {
        long long i = 1;

        while(i < n) {
            i *= 2;
        }

        return i == n;
    }
};
```

## Complexity

- Time: `O(log n)`
- Space: `O(1)`

## What I Learned

- Powers of two can be generated by repeatedly multiplying by `2`.
- Starting from `2^0 = 1` gives a simple way to check whether a number belongs to the sequence.
- Using `long long` prevents overflow while repeatedly doubling `i`.
- There is also a much faster bit-manipulation solution using `n & (n - 1)`, which is worth learning later.
